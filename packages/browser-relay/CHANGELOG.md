## [17.2.5] - 2026-08-03

### Added

- Initial release of the Chrome MV3 extension, enabling the EROS browser tool to attach to and drive existing browser tabs through `chrome.debugger`.
- Added automatic tab management that gathers actively driven tabs into a dedicated per-window **EROS** group and dissolves it cleanly on disconnect.
